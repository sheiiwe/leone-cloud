# Leone Consulting — Installazione

## Su Mac

1. Scarica e decomprimi la cartella `leone-cloud`
2. Apri il Terminale nella cartella
3. Esegui:
```bash
bash installa.sh
```

## Su Windows

### Requisiti
- **Node.js** (versione 18+): scarica da https://nodejs.org
- **Git** (opzionale): scarica da https://git-scm.com

### Installazione
1. Scarica e decomprimi la cartella `leone-cloud`
2. Apri il **Prompt dei comandi** o **PowerShell** nella cartella
3. Esegui:
```
installa.bat
```
4. Segui l'installer grafico che si aprirà

### Oppure con doppio clic
- Doppio clic su `installa.bat` nella cartella

## Aggiornamenti
Dall'app: **Impostazioni → 🔄 Controlla aggiornamenti**
